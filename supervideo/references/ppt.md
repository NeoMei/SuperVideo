# PPT 自动讲解

用于 PPT/PPTX 或按页组织的其他资料：原页视觉、基于来源的口语讲稿、自动配音、字幕和讲解视频。普通路径不要求用户录音、摄像头或放映录制。当前主路径把原生动画按静态页面处理；只说明实际保留范围。

导入后读取 page 节点、子节点、备注、原页图和 warnings。没有备注时从可见正文与图表生成有依据的讲稿；公式、缩写和布局碎片要改写成自然口语，但保留来源含义。补充解释需要可靠来源或标为待确认。

每个场景绑定同一页的真实 SourceRef 与原页图。重点动作只指向实际观察到的区域；几何不确定时先看页面像素，再提供 rect 和 evidence。页面默认全屏完整显示，底部叠加字幕；比例不同时用同页柔化背景填充，不裁正文、不拉伸。只有用户明确选择 narrated 布局才使用讲稿侧栏。

样片优先覆盖图表、公式或强调动作。实际检查页面可读性、字幕遮挡、讲述覆盖、动作时点和读音；媒体解码不能代替这些判断。
